## **Writing and Style Recommendations**

1. Write succinctly and with an active voice. Ex. [Credit Card with Gen AI](https://www.mongodb.com/docs/atlas/architecture/current/solutions-library/credit-card-application-with-generative-ai/)
2. Use second person, meaning write to the reader.
3. Avoid long paragraphs. Try to break up with bulleted lists.
4. Introduce a list with a sentence at the beginning, and end the sentence with a colon.
5. Use the full MongoDB product name on the first mention in the body text. Subsequent mentions may use the product name without MongoDB.
6. Show the abbreviation in parentheses after the spelled-out term on the first appearance.
7. Use title-style capitalization for titles and headings.

## **Style considerations**

## [**Docs Style Guide**](https://www.mongodb.com/docs/meta/style-guide/)

**Abbreviations**

- Show the abbreviation in parentheses after the spelled-out term on the first appearance.
  - access control list (ACL)
- Use abbreviations; don't alternate between the abbreviation and the spelled-out term.
- Don't show both the spelled-out term and its abbreviation in a title or heading. Show the spelled-out term and its abbreviation on first use in the text.

**Bullet points**

- Introduce a list with a sentence at the beginning, and end the sentence with a colon.
- Make all **list items parallel**. All items start with fragments, or all items use sentences.
- In a **list of only sentences, use punctuation** at the end of each item.
  - Create multiple private endpoints in a single region.
- In a **list of only fragments, don’t use punctuation** at the end of each item.
  - MongoDB Atlas
- When a list provides a series of terms and then more information, show the term or phrase in bold, and then use colons.
  - **Engine control:** Raspberry is connected to the engine, controlling it via a relay.
- Unless another order makes sense or is preferable, alphabetize list items.

**Header Capitalization**

##

- Use title-style capitalization for titles and headings. This uses initial uppercase letters for the first, last, and all the significant words in the title.
- Capitalize all words in the title except for the following types of words: articles, coordinating conjunctions (and, but, for, nor, or, yet, so), prepositions, the word to, second elements attached by hyphens.

**MongoDB Products**

- Use the full MongoDB product name on the first mention in the body text. Subsequent mentions may use the product name without MongoDB.
- Don't capitalize user’s items from MongoDB services: database, not a Database.

**Other Considerations**

- Use sentence-style capitalization for procedures.
- Don’t use _colons :_ at the end of a title, a heading, procedures and table titles.
